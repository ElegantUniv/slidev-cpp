# 교과목 개요

- 시스템 프로그래밍에 사용되는 C/C++ 언어를 배워 프로그램의 low-level 작동 메카니즘을 이해하고 python/java 언어에서 배운 객체 지향 프로그램 기법을 C++언어에서 사용하는 법을 배운다. 
- 프로그램의 low-level 작동 메카니즘을 이해하기 위하여 개발 환경은 Linux에서 text editor와 gcc comiler, gdb debugger를 사용한다.  
- STL 의 활용법을 배워 복잡한 자료구조를 쉽게 이용하도록 한다.
